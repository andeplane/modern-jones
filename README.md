# Modern Jones

Research and design for **Fuse Lane**, a modern multiplayer game clearly inspired by Sierra's *Jones in the Fast Lane* (1990).

- [docs/design/](docs/design/): how the original works (recovered from its bytecode) and the design for the new game.
- [tools/sci/](tools/sci/): the resource extractor and disassembler used for the analysis. No original game files are stored here.
- [tools/sim/](tools/sim/): a Python port of the original economy model for balance experiments.

The game itself is planned under `games/fuse-lane` in [fuse-riders](https://github.com/andeplane/fuse-riders), to share its multiplayer backend.
